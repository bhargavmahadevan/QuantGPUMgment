# GhostLayer Engineering Directives

## Always Active: gstack + Anti-Vibe-Coding Frameworks
This project strictly enforces **gstack** and anti-vibe-coding toolkits (`github/spec-kit`, `mattpocock/skills`, `ziadmomen10/zaude`, `pitimon/8-habit-ai-dev`).

### Core Rules
1. **Plan-First Gates:** Write explicit implementation plan with target files and invariants before touching code.
2. **TDD Loops (`/tdd`):** Write failing test first → verify failure via `pytest` → write minimal code → verify green → refactor.
3. **Pre-Implementation Interrogation (`/grill-me`):** Interview developer on edge cases before modifying architecture.
4. **Spec-Driven Development (`/spec-kit`):** Treat code as output generated against living specifications.
5. **No Unapproved Packages:** Never run `pip install`, `npm install`, or `pnpm add` without explicit permission.
6. **Zero Fabrication:** Never invent or simulate benchmark results.
